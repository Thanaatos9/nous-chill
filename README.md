# Dice Forge

Lanceur de dés D6 stylé — deux dés, un clic, un résultat.

## Stack

- **Next.js 15** (App Router, TypeScript)
- **Tailwind CSS** — animations et design dark/violet custom

## Démarrage local

```bash
npm install
npm run dev
```

Ouvre [http://localhost:3000](http://localhost:3000).

## Features

- 2 dés D6 avec points (pips) animés
- Animation de lancer fluide (shake + glow)
- Score total avec pop animé
- Message spécial sur `12` (CRITICAL !) et double `1` (Snake Eyes)
- Compteur de lancers

## Déploiement Coolify

1. Crée une nouvelle app sur Coolify (source : repo GitHub)
2. Build command : `npm run build`
3. Start command : `npm run start`
4. Port : `3000`
5. Variables d'env : aucune requise
